## Project 1

**Title:** Load Detector Engine Lock System

**Description:**
A hardware safety system that continuously monitors total passenger and cargo weight on a boat in real time against calibrated safe buoyancy thresholds. The system displays live load telemetry on an OLED screen and automatically cuts off the engine's starter circuit via a relay module, triggers a piezo buzzer, and flashes warning LEDs whenever the payload exceeds safe limits. A manual override switch handles emergency resets.

**Problem solved:**
Prevents boat capsizing and maritime accidents caused by passenger and cargo overloading — particularly in local ferry and small-vessel operations where weight limits are frequently ignored or misjudged. Enforces safety compliance hardware-side by physically preventing the engine from starting until excess weight is offloaded.

**Technologies & hardware used:**
- Arduino Uno
- Embedded C/C++ (Arduino IDE)
- Strain-gauge Load Cell
- HX711 24-bit ADC Amplifier Module
- 5V Inline Relay Module
- Manual Override Push-Button Switch
- 0.96" I2C OLED Display
- Active Piezo Buzzer
- Warning LEDs (220Ω resistor)
- DC-DC Buck Converter

## Project 2

**Title:** AlcoVision — Alcohol Detector Engine Lock System

**Description:**
A vehicle safety system that samples driver breath-alcohol concentration in real time using an MQ-3 alcohol sensor while monitoring driver alertness through an integrated camera. It displays live diagnostic status on an OLED screen and automatically activates a relay wired into the vehicle's ignition circuit whenever alcohol levels cross the calibrated safety threshold, physically locking the engine.

**Problem solved:**
Prevents drunk driving and fatigue-related road accidents by ensuring an impaired driver cannot start or operate the vehicle. Replaces passive warning alarms with active, hardware-enforced ignition immobilisation before the vehicle enters traffic.

**Technologies & hardware used:**
- Arduino Uno
- C/C++ (Arduino IDE)
- MQ-3 Alcohol Gas Sensor
- Integrated Camera Module (driver alertness / fatigue tracking)
- 5V Inline Relay Module (wired to starter/ignition circuit)
- I2C OLED Display
