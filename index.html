Projects

Load Detector Engine Lock System

A hardware safety system that monitors passenger and cargo weight on a boat in real time against calibrated buoyancy thresholds. When the payload exceeds safe limits it cuts the engine's starter circuit via a relay, triggers a buzzer, and flashes warning LEDs. A manual override switch handles emergency resets.

  • Arduino Uno
  • Embedded C/C++
  • HX711 ADC
  • Load Cell
  • Relay Module
  • I2C OLED

AlcoVision — Alcohol Detector Engine Lock

A vehicle safety system that samples driver breath-alcohol concentration via an MQ-3 sensor and monitors alertness through a camera module. When alcohol levels cross the safety threshold, it activates a relay wired into the ignition circuit, physically preventing the vehicle from starting.

  • Arduino Uno
  • C/C++
  • MQ-3 Sensor
  • Camera Module
  • Relay Module
  • I2C OLED
